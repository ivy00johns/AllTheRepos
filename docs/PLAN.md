# Build Plan — AllTheRepos

The roadmap and phase definitions, with the status of each phase and a closure
log of what has shipped. The full architecture rationale lives in the frozen
[`../NEW-PLAN.md`](../NEW-PLAN.md). Open work lives in [`REMAINING-WORK.md`](./REMAINING-WORK.md).

**Goal (current, widened 2026-08-21):** **production ready** — a signed, notarized,
CI-built, auto-updating macOS app. The prior goal, a **daily-driver MVP** (catalog +
launch actions + process detection + Claude tab on real data), is the first half of that
and is nearly complete. Sequencing lives in
[`plans/2026-08-21-production-readiness-plan.md`](./plans/2026-08-21-production-readiness-plan.md).

## Where we actually are

After six build waves (1–5, plus the Wave 0 foundation), the app **builds, boots, and works on real
data**, and is close to
a complete daily-driver MVP:

- **Catalog** — real FTS+vector search, tag/group persistence, manual-group filtering, design fonts.
- **Native shell** — spotlight/tray open repos, real template tray icon, dock badge tracks running servers.
- **Claude tab** — 138 real projects, real per-project usage trends, a transcript viewer.
- **Data** — embeddings now written on scan (degrade to FTS-only when Ollama is down); FTS tag-search fixed + self-healing.
- **Graph + MCP** — a curated relationship map (`repo_links` merged into the derived graph) and a standalone
  **MCP server** a Claude Code session can read and write; live watching, folders, repo moves and per-repo
  tasks round out the catalog (all Wave 5).
- **Quality** — `tsc` clean, unit **1004/0/0** (45 files), **Electron E2E 7/7**, frame-origin + shell-injection hardened.

**Wave 5 (2026-08-24–25)** then closed most of the catalog-UX intake and added a great deal
more. What remains is the tail: scanner discovery (ATR-033), the silent 200-repo cap (ATR-042),
group-membership UI (ATR-043), the distribution items (ATR-046/047/048/050/051/052), two
environment papercuts (ATR-024/025) and ATR-056/058. All in
[`REMAINING-WORK.md`](./REMAINING-WORK.md).

Baseline verified 2026-05-31 — see the [ground-truth audit](./audits/2026-05-31-ground-truth-audit.md).
Re-verified **2026-10-06** on the Wave 5 tree: `typecheck` 0 errors, `vitest` 991/0/0, Electron E2E 7/7.

| 2026-10-08 | **The window opens first, and the rest of the review's P2s are gone** — **ATR-055**: `app.whenReady()` awaited the process scan, the editor detection and the whole Claude index *before* `createMainWindow()`, so a launch could not paint until everything the first paint does not need had finished. The entry subscribes the events, registers the handlers, creates the window and boots those services behind it. The part that made it safe: each service guarded its boot with a boolean, which makes a second caller return before the work is done — harmless while nothing could reach a handler until the boot had finished, and wrong the moment the window exists first, where the first `process:list` races the trie build and the first launcher click reads the all-unavailable fallback. They memoise the promise now and every `process:*`, `launcher:*` and `claude:*` handler awaits it; a service that fails to boot is logged and reported by its panel instead of aborting the launch, which a broken Claude index could previously do to the whole catalog. **Measured with `scripts/measure-cold-start.mjs` (three launches each, same machine, back to back): window 5381ms → 1345ms, shell 6619ms → 3156ms** — the fixed build paints the shell before the old one had a window. `tests/unit/main/startup-order.spec.ts` pins the order and the per-handler awaits, because a regression here is silent. **ATR-063**: the three dead-end error screens share one `ErrorState` that keeps printing the reason and offers **Try again** (disabled while the refetch is in flight). **ATR-064**: they share one `Skeleton`, each standing in for its own content. **ATR-065**: the Claude range selector became a real radiogroup — one tab stop on the chosen option, arrows that move *and* select with a wrap, Home/End — instead of four tab stops that ignored the keys.
